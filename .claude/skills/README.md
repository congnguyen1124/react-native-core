# Claude Skills

Project-local Claude skills for this Expo React Native repository:

- `react-native-architecture`: architecture boundaries, SDK 57 compatibility, and quality gates.
- `react-native-feature`: workflow for adding or changing screens and features.
- `react-native-data-flow`: state ownership, API boundaries, TanStack Query, Zustand, Zod, and persistence.
- `git-feature-pr`: branch, commit, push, and PR title conventions.

These skills supplement `AGENT.md` and route to the Vietnamese guides in `docs/`; they do not replace either source.
